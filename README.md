# Shubhu (Spotify‑Clone)

## What it is
A music web app built with **Next.js 16**, **TypeScript**, **TailwindCSS**, and **Postgres**. It works instantly as a guest, and you can sign in with an **email + 4‑digit PIN** to sync your library across devices. It uses the public iTunes Search API for track metadata and scrapes YouTube to stream audio.

## Database & accounts

Data lives in hosted Postgres (Neon, Supabase, or any Postgres), so a laptop and a phone share the same library.

1. Create a database and copy its connection string.
2. `cp .env.example .env` and fill in:
   - `DATABASE_URL` – the Postgres connection string
   - `AUTH_SECRET` – `openssl rand -hex 32` (set once; changing it invalidates every PIN)
3. Tables are created automatically on the first request.
4. Optional: bring over data from the old local `music.db` with `npm run db:import-sqlite`.

**What syncs when signed in:** liked songs, playlists, listening history / recently played (and so the home recommendations), saved playlists, followed artists, and the (currently paused) Downloads list. Changes made on one device appear on the others when you return to the tab, and within ~45 seconds while it's open. Anything you saved as a guest on a device is merged into the account the first time you sign in on it.

**PINs:** a 4‑digit PIN is weak by nature, so it's hashed with a server secret, and every 5th wrong attempt locks the account (15 min, doubling up to 24 h). There is no email verification or PIN reset, so a forgotten PIN can't be recovered.

**Downloads (paused):** the code for saving audio on the device (IndexedDB) and syncing the list of downloaded songs is in place but switched off with `DOWNLOADS_ENABLED` in `src/lib/features.ts`, because YouTube currently rejects the audio request used to fetch songs.

## Install as a mobile app (PWA)

Shubhu is an installable web app: it opens full-screen from the home screen with its own icon, shows lock-screen controls (play/pause/next/previous), and shows an offline page if you lose connection.

- **When someone opens the site without having installed it**, a popup offers to install it. On Android/Chrome it has a one-tap **Install** button; on iPhone/iPad it shows the Safari steps (Share → Add to Home Screen). "Not now" hides it for a week. Settings → **Get the app** has the same option any time.
- **It needs HTTPS.** Installing only works on a secure site (or `localhost`), so deploy it first. On Vercel: import the repo, add `DATABASE_URL`, `DATABASE_URL_UNPOOLED` and `AUTH_SECRET` as environment variables, deploy, then open the `https://…vercel.app` URL on your phone. Use the same `AUTH_SECRET` everywhere and never change it.
- Local test with HTTPS: `npx next dev --experimental-https`.
- Files: `src/app/manifest.ts` (name, colours, icons), `public/icons/` (app icons), `public/sw.js` + `public/offline.html` (offline page; it never caches pages or API data), `src/lib/pwaInstall.ts` and `src/components/InstallPrompt.tsx` (the popup).
- **Known limit:** songs play through a hidden YouTube player, which phones usually pause when the screen locks or the app is in the background. That is the same in a browser, a PWA or a Capacitor wrapper; fixing it needs a different audio source (the same blocker as Downloads).

## Deploying to Vercel (recommended)
1. Install the Vercel CLI (if you don’t have it):
   ```bash
   npm i -g vercel
   ```
2. From the project root, run:
   ```bash
   vercel
   ```
   Follow the prompts – you can accept the default project name (`shubhu`) and link it to your Vercel account.
3. When the deployment finishes, Vercel will give you a URL like `https://shubhu.vercel.app`.

If you prefer **Netlify**:
```bash
npm i -g netlify-cli
netlify deploy --dir=.next/output --functions=functions
```
(Enable **Next.js on Netlify** in the Netlify dashboard.)

## Vercel configuration
A minimal `vercel.json` is included to tell Vercel to treat the app as a Next.js project and keep the SQLite file out of the build output.

```json
{
  "version": 2,
  "builds": [{ "src": "next.config.js", "use": "@vercel/next" }],
  "outputDirectory": ".next",
  "routes": [{ "src": "/(.*)", "dest": "/$1" }]
}
```
