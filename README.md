# Shubhu (Spotify‑Clone)

## What it is
A zero‑login music web app built with **Next.js 16**, **TypeScript**, **TailwindCSS**, and **SQLite**. It uses the public iTunes Search API for track metadata and scrapes YouTube to stream audio.

## Quick start (local)
```bash
cd C:\Users\dilip\.gemini\antigravity\scratch\spotify-clone
npm install
npm run dev   # http://localhost:3000
```

## Deploying to Vercel (recommended)
1. Install the Vercel CLI (if you don’t have it):
   ```bash
   npm i -g vercel
   ```
2. From the project root, run:
   ```bash
   vercel
   ```
   Follow the prompts – you can accept the default project name (`shubhu`) and link it to your Vercel account.
3. When the deployment finishes, Vercel will give you a URL like `https://shubhu.vercel.app`.

If you prefer **Netlify**:
```bash
npm i -g netlify-cli
netlify deploy --dir=.next/output --functions=functions
```
(Enable **Next.js on Netlify** in the Netlify dashboard.)

## Vercel configuration
A minimal `vercel.json` is included to tell Vercel to treat the app as a Next.js project and keep the SQLite file out of the build output.

```json
{
  "version": 2,
  "builds": [{ "src": "next.config.js", "use": "@vercel/next" }],
  "outputDirectory": ".next",
  "routes": [{ "src": "/(.*)", "dest": "/$1" }]
}
```
